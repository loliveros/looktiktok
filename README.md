# Sitio estático para TikTok for Developers (GitHub Pages)

Contiene: `index.html` (Web URL), `terms.html` (Terms of Service), `privacy.html` (Privacy Policy).

## Publicar en GitHub Pages
1. Crea un repo público en GitHub (por ejemplo `lookuma-tiktok-test`).
2. Sube TODOS los archivos de esta carpeta a la raíz del repo (incluido `.nojekyll`).
3. Repo → Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / carpeta `/ (root)` → Save.
4. En 1–2 minutos tendrás:
   - Web URL:  https://TU_USUARIO.github.io/lookuma-tiktok-test/
   - Terms:    https://TU_USUARIO.github.io/lookuma-tiktok-test/terms.html
   - Privacy:  https://TU_USUARIO.github.io/lookuma-tiktok-test/privacy.html
5. Abre las tres URLs en una ventana de incógnito para confirmar que cargan antes de pegarlas en TikTok.
